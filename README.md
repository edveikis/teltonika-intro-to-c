# 📚 C Programming Notes

A collection of C programs and exercises from two learning modules, covering C fundamentals through intermediate systems programming topics.

**2. Intro to C programming language 1**
- 🔢 Data Types - size and range of `float`, `int`, `char`, and related types
- 🧠 Dynamic Memory Allocation - `malloc`, `calloc`, `realloc`, and `free` examples
- 🧩 Functions - basic function definitions, return values, and returning pointers
- 🐧 How To Compile On Linux - minimal C and C++ hello-world style examples
- 👉 Pointers - pointer basics and pointer arithmetic (arrays, 2D arrays, increment/decrement, subtraction)
- 🏗️ Structures - `struct` usage, nested structs, `typedef`, and a small address-book style linked list (name, surname, number loaded from `addresses.csv`)
- 📋 Task - numbered practice exercises (file copying, address book handling, etc.)
- 📁 Working With Files - reading/writing files, binary files, flushing output
- 🔤 Working With Strings - `snprintf` and standard string functions
- ⌨️ Working With User Input - reading input, clearing the input buffer, trimming trailing newlines

**3.0 Intro to C programming language 2**
- ⚙️ Compilation - preprocessing, object files, and a build script showing separate compile/link steps
- 📦 Dynamic Array - resizable arrays with `malloc`/`calloc`/`realloc` and variable-length arrays (VLA)
- ⚠️ Error Handling - `errno`, `feof`, `ferror`, `clearerr`, `strerror`, and exit status handling
- 🧠 Memory Management - further memory allocation examples
- 📥 Queue Data Structure - a fixed-size array-based queue with enqueue/dequeue/display operations
- 📡 Signals - signal handlers, blocking/unblocking signals, `kill`, `raise`, `sigaction`, and parent/child signaling with `fork`
